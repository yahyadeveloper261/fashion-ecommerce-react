# Fashion E-Commerce React

A modern and responsive fashion e-commerce website built with **React** and **Tailwind CSS**. The project includes product browsing, categories, search, sorting, pagination, wishlist, shopping cart, checkout, product details, and dark mode.

## 🚀 Features

* 🛍️ Product listing and product details
* 👕 Men, Women, Kids & Accessories categories
* 🔎 Product search
* ↕️ Price and name sorting
* 📄 Pagination
* ❤️ Wishlist
* 🛒 Shopping cart
* ➕➖ Cart quantity controls
* 💳 Checkout page
* ✅ Order success page
* 🌙 Dark mode
* 📱 Fully responsive design
* 💾 LocalStorage for cart and wishlist data
* 🎨 Modern UI with Tailwind CSS

## 🛠️ Technologies

* React
* JavaScript
* Tailwind CSS
* React Router
* Vite
* Context API
* LocalStorage
* Git & GitHub

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/yahyadeveloper261/fashion-ecommerce-react.git
```

Go to the project folder:

```bash
cd fashion-ecommerce-react
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🏗️ Production Build

```bash
npm run build
```
